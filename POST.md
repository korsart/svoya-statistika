# Готовый текст поста

Сделал бесплатный комплект, чтобы статистика сайта не зависела только от Метрики.

Это небольшой счётчик и свой закрытый дашборд. Видно, откуда приходят посетители, какие страницы смотрят и какие действия совершают: переходы в Telegram, клики по телефону, успешные заявки.

Всё размещается на вашем хостинге. Никакого аккаунта у меня, подписки или передачи статистики на мои серверы.

Внутри код, демо, инструкция по установке и готовый промпт для нейросети. Можно разобрать комплект вместе с ней и адаптировать под свой сайт.

Первая версия для обычного хостинга с PHP. Если сайт на конструкторе без PHP, просто вставить скрипт не получится. Это базовая аналитика: без Вебвизора, рекламных расходов и автоматической замены связки Метрики с Директом. Метрику можно оставить и собирать статистику параллельно.

Код открытый, лицензия MIT. Можно использовать, менять и внедрять клиентам.

Архив и инструкция на GitHub: https://github.com/korsart/svoya-statistika

Скачайте готовый ZIP по ссылке в README и начните с файла start.html.

## Короткая версия
