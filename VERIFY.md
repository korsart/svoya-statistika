# Проверка версии 1.0.0

Проверено локально 13 октября 2026. Реальная конфигурация и статистика TRIKE не использовались.

Автоматические проверки:

- Установка с исходным ключом запрещена; неверный ключ и чужой Origin отклоняются; существующие настройки нельзя перезаписать установкой.
- Приватная папка проверяется относительно document root; пароль хранится как хеш; без пароля отчёт и экспорт закрыты.
- Сбор принимает только заданные страницы, события и категории. Неизвестные поля, адреса с параметрами и произвольные строки отклоняются.
- Повторная доставка того же ID не удваивает счётчики. Источник фиксируется на начало сессии. Лимит частоты отклоняет лишние события.
- Сроки хранения проверены на специально добавленных старых записях; повреждённый файл не перезаписывается пустым.
- До согласия браузер не создаёт сессию и не отправляет события. Отказ/отзыв останавливает новые события и отложенные повторы. Переходы между настроенными страницами учитываются.
- Приватные части URL, телефона и полей формы не передаются. Категории устройств и источников проверены. Двойная установка скрипта не создаёт второй обработчик.
- Дополнительный дашборд расходов считает только выбранный период; ошибка файла не останавливает сбор; неизвестный дашборд отвечает 404.
- Демо сгенерировано из настоящего PHP-шаблона, данные вымышлены. Архив сверяется с хешами исходников и проверяется на отсутствие реальных доступов/данных.

PHP проверялся через PHP 8.2 WASM. Это проверка логики, не нагрузочное испытание или проверка всех конфигураций хостинга. Визуальная проверка выполнена в Safari, включая мобильный viewport 390 × 844 и переключение периодов. Полная установка на стороннем реальном хостинге перед публичной эксплуатацией остаётся проверкой владельца.

Модули для реальных API рекламных сервисов и CRM не реализованы. Предоставлены интерфейс, изолированный дашборд и работающий пример локального файла расходов. Токены сервисов и реальные бюджеты в комплект не входят.
